# ProjetoSGA_WebEstetica_WesleyDourado

**Sistema de Gestão e Agendamento Estético (MVP)**  
*Projeto de Software - Experiência Prática*

## 📌 Sobre o Projeto
O **ProjetoSGA_WebEstetica_WesleyDourado** é um Produto Mínimo Viável (MVP) desenvolvido para atender às necessidades do estabelecimento parceiro **Rose Dourado Estética**, localizado na Zona Leste de São Paulo - SP.

O objetivo do sistema é eliminar o gargalo operacional do agendamento manual e descentralizado via WhatsApp e cadernos de papel, automatizando a verificação de horários disponíveis, oferecendo agendamento direto via Web Mobile-First e fornecendo um painel de gestão para acompanhamento das sessões de tratamento (como drenagens pós-operatórias).

## 🎯 Impacto Social e Alinhamento com os ODS (ONU)
* **ODS 8 — Trabalho Decente e Crescimento Econômico (Meta 8.2):** Promove a modernização tecnológica e aumento da produtividade de um microempreendimento local, reduzindo faltas (absenteísmo) e otimizando o tempo de trabalho administrativo da gestora.

## 🚀 Tecnologias Utilizadas
- **Back-end:** Python 3.12, FastAPI, Uvicorn
- **ORM / Banco de Dados:** SQLAlchemy, PostgreSQL (Supabase)
- **Front-end:** HTML5, CSS3, JavaScript (Vanilla ES6+) - Mobile-First
- **Acessibilidade:** Diretrizes WCAG AA (botões ≥ 48x48px, alto contraste e rótulos explícitos)
